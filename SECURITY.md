# Security and privacy reports

Email **help@hermap.in** privately with the affected component, a minimal reproduction, expected/actual behaviour and potential impact. Remove credentials, receipts, real account handles and survivor information from examples. Do not publish a working exploit or sensitive evidence in an issue.

Test against your own local installation using fictional data. Do not access other people’s submissions, scrape private records, run denial-of-service tests or probe the public service without explicit scope and permission. If sensitive data is encountered accidentally, stop accessing it and report the minimum necessary detail privately.

There is no paid bounty or guaranteed response time currently. Coordinate publication with maintainers after a fix and verification. This reporting channel is not an emergency response service; in immediate danger in India call 112.
