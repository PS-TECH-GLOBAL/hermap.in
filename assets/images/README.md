# HerMap brand assets

The owner supplied `site/logo-website.png` for the website (500×163) and
`site/HerMap.in-favicon.png` for the favicon (200×200). The original artwork is
used unchanged. The website logo already includes the official tagline, so no
duplicate tagline is rendered below it. Larger source artwork remains in `site/`.

Brand colours: deep purple `#240348` sampled from the artwork, with the owner's
chosen softer coral `#FF6B6B` as the platform secondary colour. Text links,
search/location/lock/map-help/emergency icons and map controls use coral.
The report button has a coral background with white text and a white plus.
Preserve the original artwork, proportions and transparency.
